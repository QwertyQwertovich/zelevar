# Зельевар · Potion Brewer

Головоломка-сортировка: разливайте зелья по колбам, пока каждый цвет не окажется в своей колбе.

**Играть в браузере:** https://qwertyqwertovich.github.io/zelevar/
**Скачать для Android:** [последний релиз](https://github.com/QwertyQwertovich/zelevar/releases/latest)

- 1000 уровней, каждый проверен решателем
- 12 механик: тайные слои, лёд, воронки, замки, высокие колбы, печати, краны, рецепты на ходы, блицы и другие
- Работает без интернета и без рекламы
- Лавка дизайнов за звёзды, подарок дня, «Зелье дня», достижения
- 8 языков: русский, English, українська, Deutsch, français, español, português, 中文
